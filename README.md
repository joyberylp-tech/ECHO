# ECHO – Personal Notes Management System

ECHO is a Python-based personal notes management application built using Flask and SQLite.

## Technologies Used
- Python 3.13
- Flask
- SQLite
- HTML
- CSS
- Flask-WTF

## Features
- User Registration
- User Login
- Create Notes
- Edit Notes
- Delete Notes
- Search Notes
- SQLite Database Integration

## Live Website

https://JoyBerylPrabhu.pythonanywhere.com

## Deployment

ECHO is deployed using PythonAnywhere.

Deployment configuration:
- Hosting: PythonAnywhere
- Framework: Flask
- Python Version: 3.13
- Database: SQLite
- WSGI Entry Point: flask_app.py
- Flask Application Object: app

## Local Installation

1. Clone the repository:

   git clone https://github.com/joyberylp-tech/ECHO.git

2. Navigate into the project:

   cd ECHO

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python flask_app.py

5. Open:

   http://127.0.0.1:5000
